<h1 align="center">Tic-Tac-Toe (C++)</h1>
<p align="center">
  <strong>Game Type:</strong> 2-Player Console Game <br>
  <strong>Developer:</strong> Sunny Eljohn Lico
</p>

<hr>

<h2>Project Description</h2>
<ul>
  <li>A classic <b>Tic-Tac-Toe</b> game built using C++ for a terminal/console environment.</li>
  <li>Features a <b>Two-Player mode</b> where users take turns marking spaces on a 3x3 grid.</li>
  <li>Implements core programming logic for win-detection and handling tie games.</li>
</ul>

<h2>Key Features</h2>
<ul>
  <li><b>Interactive Grid:</b> A visual 3x3 board that updates after every move.</li>
  <li><b>Win Validation:</b> Automatically checks for <b>Horizontal, Vertical, and Diagonal</b> matches.</li>
  <li><b>Turn Management:</b> Alternates between Player 1 (X) and Player 2 (O) seamlessly.</li>
  <li><b>Input Validation:</b> Prevents players from choosing occupied spaces or invalid coordinates.</li>
</ul>

<h2>Technical Specifications</h2>
<ul>
  <li><b>Logic:</b> Uses a <b>2D Array</b> to store and manage the game board state.</li>
  <li><b>Language:</b> C++</li>
  <li><b>Year:</b> 2023</li>
</ul>

<h2>How to Play</h2>
<ol>
  <li>Compile the code: <code>g++ TicTacToe.cpp -o TicTacToe</code></li>
  <li>Run the game: <code>./TicTacToe</code></li>
  <li>Enter the row and column number to place your mark.</li>
</ol>
