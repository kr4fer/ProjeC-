<h1 align="center">SunnYSTEM: AI Chat Console</h1>
<p align="center">
  <strong>Project Type:</strong> Basic AI Simulation <br>
  <strong>Developer:</strong> Sunny Eljohn Lico

<hr>

<h2>Project Description</h2>
<ul>
  <li><b>SunnYSTEM</b> is a C++ console application that simulates a conversation between a user and a basic AI entity.</li>
  <li>It uses <b>Natural Language Processing (NLP)</b> fundamentals to interpret user inputs and provide relevant responses.</li>
  <li>Designed to demonstrate <b>string manipulation</b> and <b>decision-making algorithms</b> in a terminal environment.</li>
</ul>

<h2>Core Objectives</h2>
<ul>
  <li><b>Interactive Dialogue:</b> Create a responsive environment where the system "listens" and "talks" back to the user.</li>
  <li><b>Keyword Recognition:</b> Identify specific phrases or words within user input to trigger appropriate AI behaviors.</li>
  <li><b>System Personality:</b> Establish a unique "SunnYSTEM" persona through pre-defined conversational scripts.</li>
</ul>

<h2>Key Features</h2>
<ul>
  <li><b>Pattern Matching:</b> The AI analyzes sentence structures to determine the intent of the user.</li>
  <li><b>Contextual Responses:</b> Provides different answers based on the tone or specific keywords detected (e.g., greetings, questions, or commands).</li>
  <li><b>Dynamic Loop:</b> Runs a continuous conversation thread until the user initiates a "goodbye" or "exit" command.</li>
  <li><b>Error Handling:</b> Includes a default fallback response for unrecognized inputs to keep the conversation flowing.</li>
</ul>

<h2>Technical Specifications</h2>
<ul>
  <li><b>Language:</b> C++ (.cpp)</li>
  <li><b>Logic:</b> Utilizes <code>std::string</code> libraries and nested <code>if-else</code> or <code>switch</code> logic for response mapping.</li>
  <li><b>Year:</b> 2023</li>
</ul>

<h2>How to Initialize SunnYSTEM</h2>
<ol>
  <li>Compile the system: <code>g++ SunnYSTEM.cpp -o SunnYSTEM</code></li>
  <li>Launch the AI: <code>./SunnYSTEM</code></li>
  <li>Type your message and press <b>Enter</b> to chat.</li>
</ol>
